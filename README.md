# Daytona USA Reborn

A work in progress from **Retro Upgrade Atelier**. The goal is to improve the presentation of Daytona USA on modern displays while preserving the feel of the arcade game.

**Download status:** The videos show development builds. There is no public executable available for download at this time. If a public build becomes available, this page will link to it.

## Gameplay previews

- [Expert circuit · Ultrawide and improved draw distance](https://www.youtube.com/watch?v=XdRGgOazVyU)
- [Dinosaur Canyon · Ultrawide, draw distance and 3D cars](https://www.youtube.com/watch?v=kseU81hm6ow)
- [First native PC gameplay preview](https://www.youtube.com/watch?v=Ose33UPZsVc)

## Feedback from the previews

Viewers pointed out that the Expert tower pops in and out, some colors look washed out, and the cloud spacing looks odd. They also asked for more control over steering sensitivity and response on a gamepad. These are useful test cases for the next previews. The videos show work in progress.
